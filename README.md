# FinancialAnalyst

Project structure for a multi-agent financial analysis application.

## Layout

- `app/api`: API endpoints and route registration
- `app/agents`: workflow agents
- `app/workflows`: orchestration graph
- `app/services`: external integrations and domain services
- `app/repositories`: data access layer
- `app/models`: database models and schemas
- `app/prompts`: prompt templates
- `scripts`: maintenance and data tasks
- `tests`: automated tests
